# Status

Accepted.

# Decision

The Instruction Reference, ISA database, Programmer Guide, stream RTL specification, Hardware Block Catalog, and Quick Reference must explicitly document MODE and the two-dimensional stream fields. QCFG field aliases must appear in assembly-facing documents, while QCFG remains the canonical hardware encoding.

# Affected canonical documents

- AUR-ARCH-005 Instruction Reference

- AUR-ARCH-006 Assembly Language Programmer Guide

- AUR-ARCH-007 Microarchitecture

- AUR-RTL-002H Stream Engines

- AUR-HW-012 Hardware Block Catalog

- AUR-REF-001 Quick Reference Card

- Machine-readable ISA database
