# Decision Logs

Start here:

- `ARCHITECTURE_DECISION_LOG_CURRENT.md` / `.docx`
- `DOCUMENTATION_DECISION_LOG_CURRENT.md` / `.docx`

The `source-registers/` directory contains the original ADR register, expanded ADR set, architecture rationale/decision log, original Documentation Decision Register, and bytecode DDR addendum.

The `architecture-records/` and `documentation-records/` directories contain individual later ADR and DDR documents.

Superseded records are retained for history and marked in the consolidated logs.
