# Aurora Project v1.2

Aurora is a low-cost, low-power processor architecture combining low-to-mid-range fixed-point DSP throughput with MCU-class deterministic control.

## Repository layout

- `00_Project_Management` - master index, ADRs, architecture bible
- `10_Architecture` - ABI, ISA, memory map, microarchitecture, compiler model
- `20_Implementation` - RTL, simulator, FPGA and ASIC plans
- `30_Verification` - ISA tests, benchmarks, coverage and validation plans
- `40_Software` - programmer guides, examples, libraries, intrinsics and SDK
- `50_Product` - Aurora-L/M/P profiles and customer-facing material

## Governance

Architectural changes begin in the ADR register and Architecture Bible, then propagate to specifications and machine-readable databases.
